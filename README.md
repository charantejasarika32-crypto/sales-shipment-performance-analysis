# Sales & Shipment Performance Analysis

##  Project Overview

This project analyzes sales and shipment performance using Excel and Power BI. The analysis focuses on revenue, profit, shipments, products, salespersons, and geographical performance.

##  Objective

The objective of this project is to analyze business performance, identify sales trends, evaluate product and salesperson performance, and provide useful insights through an interactive Power BI dashboard.

##  Tools Used

- Excel
- Power BI
- Power Query
- DAX

## Key KPIs

- Total Sales: $141M
- Total Boxes: 9M
- Shipment Count: 25K
- Total Profit: $81M
- Profit Percentage: 57.3%

##  Analysis Performed

- Sales and profit analysis
- Year-over-year sales comparison
- Monthly sales trends
- Product performance analysis
- Top-performing products
- Salesperson performance
- Geographical sales analysis
- Shipment distribution
- Product profitability analysis

##  Dashboard

The Power BI dashboard provides an interactive view of sales, shipment, product, salesperson, and geographical performance.

![Sales & Shipment Dashboard](dashboard%20for%20sales.jpeg)

##  Key Insights

- Identified the top-performing products based on sales.
- Compared sales and profit performance across products.
- Analyzed salesperson performance based on sales, boxes, and profit percentage.
- Evaluated sales distribution across different geographical regions.
- Compared current-year performance with previous-year performance.
